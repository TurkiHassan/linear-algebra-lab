تحليل القيم المفردة

Singular Value Decomposition — rotate, stretch, rotate: the one factorisation that works for every matrix

~40 دقيقة · المتطلب: الدرس 0023 (القطرنة) و0017 (المصفوفات المتعامدة)

١ لماذا لا تكفي القطرنة؟Eigendecomposition needs a square matrix with enough eigenvectors — most matrices have neither

القطرنة في الدرس السابق اشترطت شرطين: أن تكون المصفوفة مربعة، وأن تملك متجهات ذاتية تكفي أساساً. ومصفوفة البيانات الحقيقية لا تحقق الأول أصلاً: 1000 صورة في 784 بكسل مصفوفة مستطيلة، ولا معنى فيها لـ Ax = λx لأن الطرفين في فضاءين مختلفين. نحتاج تعميماً يعمل دائماً — وهو تحليل القيم المفردة (SVD).

تشبيه: تشكيل الطين

لتشكّل قطعة طين تفعل ثلاثة أشياء بالترتيب: تُديرها لتضبط محاورها، ثم تضغط أو تمدّ على كل محور، ثم تُديرها إلى الوضع النهائي. وهذا حرفياً ما تقوله A = UΣVᵀ: دوران، فتمديد، فدوران. (Orient, squeeze, orient again.)

فكرة أساسية

القاعدة الذهبية: A = UΣVᵀ موجود لكل مصفوفة A ∈ ℝ^(m×n) بلا استثناء. وU وV متعامدتان — أي دورانان — وΣ قطرية عناصرها σ₁ ≥ σ₂ ≥ … ≥ 0 وتُسمّى القيم المفردة (singular values).

توقّع قبل أن تجرّب

مصفوفة A بحجم 3×2. هل لها تفكيك ذاتي؟ وهل لها تحليل قيم مفردة؟

اكشف الجواب

لا تفكيك ذاتي لها: Ax يقع في ℝ³ وλx في ℝ²، فالمعادلة Ax = λx بلا معنى أصلاً. وأما SVD فموجود — ومصفوفتاه U بحجم 3×3 وV بحجم 2×2، فلكل فضاء دورانه. وهذا هو الفرق الجوهري: التفكيك الذاتي يغيّر الأساس مرة، وSVD يغيّره مرتين لأن الفضاءين مختلفان. (SVD always exists; EVD often does not.)

٢ الخطوات الثلاث مرسومةV-transpose rotates, Sigma stretches, U rotates again

أوضح ما في SVD هو أثره على دائرة الوحدة. ادفع الدائرة في Vᵀ فتدور بلا تشوّه، ثم في Σ فتنسحق إلى قطع ناقص محاوره على المحورين، ثم في U فيدور القطع إلى وضعه النهائي. وطولا محوري القطع الناتج هما بالضبط σ₁ وσ₂.

مثال محسوب

تحليل كامل بالورقة والقلم: من AᵀA إلى المصفوفات الثلاث.

A = [ 3  0 ]
    [ 4  5 ]

step 1 -- build A^T A, which is symmetric and positive semidefinite

  A^T = [ 3  4 ]
        [ 0  5 ]

  A^T A = [ 3  4 ] [ 3  0 ] = [ 9+16   0+20 ] = [ 25  20 ]
          [ 0  5 ] [ 4  5 ]   [ 0+20   0+25 ]   [ 20  25 ]

step 2 -- its eigenvalues are the SQUARES of the singular values

  tr = 50 ,  det = 625 - 400 = 225
  L^2 - 50L + 225 = 0
  L = (50 +- sqrt(2500 - 900)) / 2 = (50 +- 40) / 2
  L1 = 45 ,  L2 = 5

  sigma1 = sqrt(45) = 6.7082        sigma2 = sqrt(5) = 2.2361

step 3 -- right singular vectors: eigenvectors of A^T A

  L = 45 :  A^T A - 45I = [ -20   20 ]   ->  x1 = x2
                          [  20  -20 ]
            v1 = (1, 1) / sqrt2

  L = 5  :  A^T A - 5I  = [ 20  20 ]     ->  x1 = -x2
                          [ 20  20 ]
            v2 = (1, -1) / sqrt2

  check   <v1, v2> = (1 - 1) / 2 = 0                    orthonormal   OK

step 4 -- left singular vectors: u = A v / sigma

  A v1 = (1/sqrt2) ( 3+0 , 4+5 ) = (1/sqrt2)(3, 9)
  u1   = A v1 / sigma1 = (3, 9) / (sqrt2 * 3*sqrt5) = (1, 3) / sqrt10

  A v2 = (1/sqrt2) ( 3-0 , 4-5 ) = (1/sqrt2)(3, -1)
  u2   = A v2 / sigma2 = (3, -1) / (sqrt2 * sqrt5)  = (3, -1) / sqrt10

  check   <u1, u2> = (3 - 3) / 10 = 0                   orthonormal   OK

the determinant check, almost free

  |det A| = |3*5 - 0*4| = 15
  sigma1 * sigma2 = sqrt(45) * sqrt(5) = sqrt(225) = 15               OK

آخر سطر قاعدة عامة: حاصل ضرب القيم المفردة هو القيمة المطلقة للمحدد. فالقيم المفردة تقيس التمدد على كل محور، وحاصل ضربها هو تغيّر المساحة.

انتبه

لا تخلط القيم المفردة بالقيم الذاتية. القيم الذاتية قد تكون سالبة أو مركّبة، والقيم المفردة لا تكون إلا موجبة أو صفراً. وهما يتطابقان في حالة واحدة: مصفوفة متماثلة معرّفة موجبة. (Singular values are never negative.)

٣ من أين تأتي المصفوفات الثلاث؟Right vectors from A-transpose-A, left vectors from A v over sigma

الحيلة كلها في ملاحظة واحدة: AᵀA متماثلة دائماً ونصف معرّفة موجبة دائماً، مهما كان شكل A. والنظرية الطيفية تنطبق عليها إذاً، فنقطرنها متعامداً: AᵀA = VDVᵀ. من هنا تأتي V، وقيمها الذاتية غير السالبة جذورها هي σᵢ، وأعمدة U تُبنى بـ uᵢ = Avᵢ / σᵢ.
