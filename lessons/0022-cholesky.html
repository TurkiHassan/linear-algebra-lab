تحليل LU وتشوليسكي

LU & Cholesky — elimination written as a product, and the square root of a positive definite matrix

~35 دقيقة · المتطلب: الدرس 0003 (الحذف الغاوسي) و0016 (المصفوفة المعرّفة الموجبة)

١ تحليل LU: الحذف الغاوسي مكتوباً كضربEvery elimination step is a lower-triangular matrix — collect them and you get A = LU

في الدرس 0003 حذفتَ غاوسياً حتى بلغت مصفوفة مثلثية عليا. ما لم يُقَل هناك: كل خطوة حذف هي ضربٌ في مصفوفة، وهذه المصفوفات مثلثية سفلى. فإن جمعتها كلها خرج لك A = LU: مثلثية سفلى فيها مضاعفات الحذف، ومثلثية عليا هي نتيجة الحذف.

تشبيه: دفتر الخطوات

حين تحذف غاوسياً تُتلف المصفوفة الأصلية خطوةً خطوة. تحليل LU يحتفظ بدفتر الخطوات: U هي النتيجة، وL هي سِجلّ ما فعلتَه للوصول إليها — وبهما تستعيد الأصل متى شئت. (U is where you arrived; L is how you got there.)

فكرة أساسية

الفائدة عملية: لحلّ Ax = b بعدة قيم مختلفة لـ b، تُحلّل مرة واحدة ثم تحلّ مسألتين مثلثيتين لكل b — Ly = b نزولاً ثم Ux = y صعوداً. التحليل مرة، والاستعمال مرات.

توقّع قبل أن تجرّب

مصفوفة متماثلة عناصر قطرها كلها موجبة. هل هي حتماً معرّفة موجبة؟

اكشف الجواب

لا. خذ [[1, 3], [3, 1]]: قطرها موجب، لكن محددها 1 − 9 = −8 سالب، فليست معرّفة موجبة ولا تشوليسكي لها. القطر الموجب شرط لازم لا كافٍ — والفحص الصحيح أن تكون كل المحددات الرئيسة الصدرية موجبة. (A positive diagonal is necessary, not sufficient.)

آلة LU

أدخل مصفوفة 2×2 — اللوحة تحذف خطوة واحدة وتكتب L وU ثم تعيد ضربهما للتحقق

٢ تشوليسكي: جذرٌ تربيعي للمصفوفةA = L L-transpose, for symmetric positive definite matrices only

للعدد الموجب جذرٌ تربيعي: 9 = 3 × 3. وللمصفوفة المتماثلة المعرّفة الموجبة (symmetric positive definite) نظيرُ ذلك: A = LLᵀ حيث L مثلثية سفلى قطرها موجب. وهذا التحليل وحيد، ويُسمّى عامل تشوليسكي (Cholesky factor).

حاسبة تشوليسكي

أدخل مصفوفة متماثلة — اللوحة تفحص التعريف الموجب أولاً، ثم تستخرج L

المصفوفة المفحوصة هي [[a, b], [b, d]] — متماثلة بالبناء

مثال محسوب

التحليلان جنباً إلى جنب: الأول لأي مصفوفة، والثاني للمعرّفة الموجبة وحدها.

part 1 -- LU, which is Gaussian elimination written as a product

A = [ 2  1 ]
    [ 6  5 ]

one elimination step:   R2 <- R2 - 3*R1        multiplier m21 = 6 / 2 = 3

  U = [ 2  1 ]           what the elimination left behind
      [ 0  2 ]

  L = [ 1  0 ]           the multiplier, kept instead of thrown away
      [ 3  1 ]           (ones on the diagonal, by convention)

check   L U = [ 1*2 + 0*0 ,  1*1 + 0*2 ] = [ 2  1 ]
              [ 3*2 + 1*0 ,  3*1 + 1*2 ]   [ 6  5 ]   = A       OK


part 2 -- Cholesky, for a symmetric positive definite matrix

A = [ 4  2 ]      symmetric ?   yes, a12 = a21
    [ 2  5 ]      positive definite ?
                    leading minor 1 :  4 > 0
                    leading minor 2 :  det = 4*5 - 2*2 = 16 > 0
                  -> yes

solve A = L L^T with L lower triangular and a positive diagonal

  l11 = sqrt(a11)              = sqrt(4)      = 2
  l21 = a21 / l11              = 2 / 2        = 1
  l22 = sqrt(a22 - l21^2)      = sqrt(5 - 1)  = 2

  L = [ 2  0 ]
      [ 1  2 ]

check   L L^T = [ 2  0 ] [ 2  1 ] = [ 4        2    ] = A       OK
                [ 1  2 ] [ 0  2 ]   [ 2    1 + 4    ]

the determinant, now almost free

  det(A) = det(L) * det(L^T) = det(L)^2 = (2 * 2)^2 = 16
  compare 4*5 - 2*2 = 16                                        OK

آخر سطر هو سبب شعبية تشوليسكي في الحوسبة: بعد التحليل يصير المحدد حاصل ضرب القطر مربّعاً — بلا أي عمل إضافي.

انتبه

تشوليسكي يشترط شرطين معاً: التماثل و التعريف الموجب. التماثل وحده لا يكفي، والقطر الموجب وحده لا يكفي. وإن حاولتَ الحساب على مصفوفة غير معرّفة موجبة فستطلب جذر عدد سالب — والبرنامج سيخبرك بذلك بخطأ لا بنتيجة خاطئة. (The algorithm fails loudly, which is a feature.)

٣ لماذا يهتم تعلّم الآلة بهذا التحليل؟Cholesky turns a covariance matrix into a sampler

كل توزيع غاوسي متعدد المتغيرات له مصفوفة تغاير (covariance matrix)، وهي متماثلة معرّفة موجبة دائماً. وعامل تشوليسكي لها هو الآلة التي تحوّل عيّنات عشوائية مستقلة إلى عيّنات مرتبطة بالنمط المطلوب: خذ z من دائرة الوحدة العشوائية، واضرب Lz، فتحصل على الشكل البيضوي الصحيح.

آلة الارتباط

حرّك معامل الارتباط ρ — اللوحة ترسم صورة دائرة الوحدة تحت L، وهي بالضبط شكل السحابة الغاوسية
