القطرنة والنظرية الطيفية

Diagonalization — A = P D P-inverse turns matrix powers into number powers, and symmetry makes P orthogonal

~40 دقيقة · المتطلب: الدرس 0021 (القيم الذاتية) و0018 (غرام–شميت)

١ لماذا نريد القطر؟ لأن القوى تصير سهلةA = P D P-inverse, so A to the k is P D-to-the-k P-inverse

المصفوفة القطرية سهلة إلى حدّ السذاجة: رفعها لقوّة هو رفع كل عنصر قطري لتلك القوّة، ومحددها حاصل ضرب القطر، ونظيرها مقلوب القطر. فلو استطعنا كتابة أي مصفوفة بصورة A = PDP⁻¹ لورثنا هذه السهولة كلها: Aᵏ = PDᵏP⁻¹ — ضربتان ومصفوفة قطرية بدل k ضربة كاملة.

تشبيه: الترجمة

لتضرب عددين كبيرين يدوياً، تحوّلهما إلى لوغاريتمات فيصير الضرب جمعاً، ثم تعود. القطرنة الشيء نفسه: انتقل إلى أساس المتجهات الذاتية حيث كل شيء ضربٌ في عدد، اعمل هناك، ثم عُد. (Change basis, work in the easy world, change back.)

فكرة أساسية

القاعدة الذهبية: أعمدة P هي المتجهات الذاتية، وقطر D هو القيم الذاتية بالترتيب نفسه. وهذا يشترط أن تكون المتجهات الذاتية أساساً لـ ℝⁿ — أي أن تكفي عدداً واستقلالاً.

توقّع قبل أن تجرّب

مصفوفة 2×2 لها قيمة ذاتية واحدة مكررة. هل هي حتماً قابلة للقطرنة؟

اكشف الجواب

لا، والحالتان تُظهران أن التكرار ليس هو المشكلة. المصفوفة [[2, 1], [0, 2]] تعددها الجبري 2 لكن الهندسي 1 — متجه ذاتي واحد فقط، فلا تُقطرَن. أما 2I فتعددها الهندسي 2 وهي قطرية أصلاً. المشكلة نقص المتجهات المستقلة لا تكرار الجذر. (Repetition is fine; a missing eigenvector is not.)

٢ التعدد الجبري والهندسي: متى تفشل القطرنة؟A is diagonalizable exactly when the geometric multiplicities add up to n

التعدد الجبري (algebraic multiplicity) ورمزه α هو عدد مرات ظهور الجذر في الكثيرة المميزة. والتعدد الهندسي (geometric multiplicity) ورمزه ζ هو بُعد الفضاء الذاتي — أي عدد المتجهات الذاتية المستقلة لتلك القيمة. ودائماً ζ ≤ α. والقطرنة ممكنة إذا وفقط إذا تساوى مجموعاهما وبلغا n.

مثال محسوب

مصفوفة متماثلة تُقطرَن قطرنةً متعامدة — ثم نستعملها لحساب قوّتها.

A = [ 2  1 ]        symmetric, so the Spectral Theorem promises an
    [ 1  2 ]        orthonormal eigenbasis before we compute anything

eigenvalues

  tr(A) = 4 ,  det(A) = 3
  p(L) = L^2 - 4L + 3 = (L - 1)(L - 3)
  L1 = 1 ,  L2 = 3

eigenvectors

  L = 1 :   A - I = [ 1  1 ]     x1 + x2 = 0   ->   p1 = (1, -1)
                    [ 1  1 ]

  L = 3 :   A - 3I = [ -1   1 ]  -x1 + x2 = 0  ->   p2 = (1, 1)
                     [  1  -1 ]

  perpendicular ?   <p1, p2> = 1*1 + (-1)*1 = 0        yes, as promised

normalise, and P becomes orthogonal

  |p1| = |p2| = sqrt(2)
  q1 = (1/sqrt2)( 1, -1)        q2 = (1/sqrt2)(1, 1)

  P = (1/sqrt2) [ 1  1 ]        D = [ 1  0 ]        P^-1 = P^T
                [ -1 1 ]            [ 0  3 ]

the payoff: A squared, without squaring A

  A^2 = P D^2 P^T ,   D^2 = [ 1  0 ]
                            [ 0  9 ]

  D^2 P^T = (1/sqrt2) [ 1  0 ] [ 1  -1 ] = (1/sqrt2) [ 1  -1 ]
                      [ 0  9 ] [ 1   1 ]             [ 9   9 ]

  P (that) = (1/2) [ 1  1 ] [ 1  -1 ] = (1/2) [ 10   8 ] = [ 5  4 ]
                   [ -1 1 ] [ 9   9 ]         [  8  10 ]   [ 4  5 ]

  direct check:  A*A = [ 2  1 ] [ 2  1 ] = [ 5  4 ]        OK
                       [ 1  2 ] [ 1  2 ]   [ 4  5 ]

  for k = 2 the shortcut saves nothing.
  for k = 50 it is the difference between 50 matrix products and one.

لاحظ أن P⁻¹ = Pᵀ هنا — وهذا ليس حظاً بل نتيجة تماثل A. ولهذا تُسمّى قطرنةً متعامدة.

انتبه

ζ ≤ α دائماً، والفجوة بينهما هي سبب فشل القطرنة الوحيد. ومصفوفة القصّ [[1, 1], [0, 1]] هي المثال القياسي: جذر مكرر، ومتجه ذاتي واحد، فلا قطرنة لها مهما حاولت. (A shear is the canonical non-diagonalizable matrix.)

٣ النظرية الطيفية: التماثل يضمن كل شيءA is orthogonally diagonalizable if and only if A is symmetric

النظرية الطيفية (Spectral Theorem) تقول: إن كانت A متماثلة حقيقية فقيمها الذاتية كلها حقيقية، ومتجهاتها الذاتية لقيم مختلفة متعامدة، ويوجد لها أساس ذاتي متعامد متجانس. وحتى عند تكرار الجذر، يمكن بناء أساس متعامد داخل الفضاء الذاتي بـغرام–شميت الذي تعلّمته في الدرس 0018.

فكرة أساسية

مصفوفة التغاير في البيانات متماثلة دائماً، فالنظرية الطيفية تنطبق عليها دائماً. ولهذا يوجد لتحليل المكوّنات الرئيسة (PCA) اتجاهات متعامدة مرتّبة — وهي بالضبط أعمدة P في القطرنة المتعامدة لمصفوفة التغاير.
