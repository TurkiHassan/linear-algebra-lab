القيم والمتجهات الذاتية

Eigenvalues & Eigenvectors — the directions a matrix only stretches, and the factor by which it stretches them

~40 دقيقة · المتطلب: الدرس 0020 (الأثر والكثيرة المميزة)

١ اتجاه لا يدور: Ax = λxAn eigenvector is a direction the matrix only scales — never turns

معظم المتجهات تدور عند ضربها في مصفوفة: تخرج بزاوية غير التي دخلت بها. لكنّ بعض الاتجاهات تصمد — يخرج المتجه على استقامته الأولى، أطول أو أقصر فحسب. هذا هو المتجه الذاتي (eigenvector)، ومعامل الطول هو القيمة الذاتية (eigenvalue). شرطهما سطر واحد: Ax = λx مع x ≠ 0.

تشبيه: تيار النهر

ألقِ ورقة في نهر فتنجرف وتدور. لكن على محور التيار تماماً تمضي الورقة في خط مستقيم، يزيد سرعتها أو ينقصها ولا يغيّر وجهتها. محور التيار هو المتجه الذاتي، والسرعة هي القيمة الذاتية. (On the axis of the current, direction survives.)

فكرة أساسية

القاعدة الذهبية: أربع عبارات مترادفة تماماً: λ قيمة ذاتية ⟺ (A − λI)x = 0 لها حل غير صفري ⟺ rk(A − λI) < n ⟺ det(A − λI) = 0. الأخيرة هي التي نحسبها، والأولى هي التي نريدها.

توقّع قبل أن تجرّب

مصفوفة دوران في المستوى بزاوية 30°. كم متجهاً ذاتياً حقيقياً لها؟

اكشف الجواب

صفر. الدوران يحرّك كل اتجاه، فلا يبقى أحدٌ على استقامته — ولا وجود لاتجاه يقتصر التحويل عليه بالتمديد. الجذور موجودة لكنها مركّبة، والمميّز tr² − 4·det سالب. الاستثناءان الوحيدان هما 0° و180°. (A real rotation has no real eigenvector.)

٢ الفضاء الذاتي: E_λ = ker(A − λI)Eigenvectors are never unique — they fill an entire subspace

إن كان x متجهاً ذاتياً فكذلك 2x و−x وكل مضاعف غير صفري له: A(cx) = cAx = cλx = λ(cx). فمجموعة المتجهات الذاتية لقيمة ذاتية واحدة ليست متجهاً بل فضاءً جزئياً كاملاً يسمّى الفضاء الذاتي (eigenspace)، وهو بالضبط نواة A − λI التي عرفتها في الدرس 0013.

مثال محسوب

نكمل مصفوفة الدرس السابق: عرفنا الجذرين، والآن نستخرج اتجاهيهما.

A = [ 4  2 ]        from lesson 0020:   L1 = 2 ,  L2 = 5
    [ 1  3 ]

eigenvector for L = 5      solve (A - 5I) x = 0

  A - 5I = [ 4-5    2  ] = [ -1   2 ]
           [  1    3-5 ]   [  1  -2 ]

  row 1:  -x1 + 2*x2 = 0   ->   x1 = 2*x2
  row 2:   x1 - 2*x2 = 0        the SAME equation
                                (it must be: the matrix is singular by construction)

  take x2 = 1   ->   x = (2, 1)
  E5 = span{ (2, 1) }

  check   A*(2,1) = ( 4*2 + 2*1 , 1*2 + 3*1 ) = (10, 5) = 5*(2, 1)     OK

eigenvector for L = 2      solve (A - 2I) x = 0

  A - 2I = [ 2  2 ]
           [ 1  1 ]

  x1 + x2 = 0   ->   x1 = -x2
  take x2 = -1  ->   x = (1, -1)
  E2 = span{ (1, -1) }

  check   A*(1,-1) = ( 4 - 2 , 1 - 3 ) = (2, -2) = 2*(1, -1)           OK

two distinct eigenvalues  ->  the eigenvectors are independent

  det [ 2   1 ] = 2*(-1) - 1*1 = -3   != 0
      [ 1  -1 ]

  so { (2,1) , (1,-1) } is a basis of R^2 made of eigenvectors
  -- which is exactly what lesson 0023 will need.

لاحظ أن صفَّي A − λI تكرّرا. هذا ليس مصادفة: اخترنا λ تحديداً ليصير المحدد صفراً، والمحدد الصفري يعني صفوفاً مرتبطة.

انتبه

لا تقل «المتجه الذاتي للقيمة λ» بل «متجه ذاتي». المتجهات الذاتية غير وحيدة أبداً: كل مضاعف غير صفري يصلح. وحين نحتاج واحداً بعينه نُوحّد طوله إلى 1، وحتى حينها تبقى الإشارة حرة. (Eigenvectors are unique only up to scale.)

٣ معرض الهندسة: خمسة تحويلات وخمسة أطيافStretch, shear, rotate, collapse — each has a signature in its eigenvalues

القيم الذاتية ليست أرقاماً مجرّدة: هي وصفٌ لما يفعله التحويل بالفضاء. وأمثلة المحاضرة الخمسة تغطّي الحالات كلها — من التمديد النقي إلى الانهيار الكامل. والمحدد يبقى حارساً على المساحة: det(A) = Πλᵢ هو معامل تغيّر المساحة.
