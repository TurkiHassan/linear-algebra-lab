Affine Spaces — a subspace that slid away from the origin, and why Ax = b lives there

~35 دقيقة · المتطلب: الدرس 0013 (التطبيقات الخطية)

١ خطي أم أفيني؟ الفرق إزاحة واحدةLinear: f(x) = Ax · Affine: f(x) = Ax + b

الدالة f(x) = Ax خطية، والدالة f(x) = Ax + b أفينية (affine): خطية زائد إزاحة. وفي الاستعمال اليومي يخلط الناس بينهما — حتى إن «الانحدار الخطي» في تعلّم الآلة أفيني في حقيقته، لأن فيه حدّاً ثابتاً b.

تشبيه: المصعد والطابق

التطبيق الخطي مصعد يبدأ دائماً من الطابق الأرضي (الصفر). أما الأفيني فمصعد بدأ من الطابق الثالث: الحركة نفسها، ونقطة الانطلاق مزاحة. (Same motion, shifted start.)

فكرة أساسية

القاعدة الذهبية: اختبار واحد يفصلهما: هل f(0) = 0؟ إن نعم فخطي، وإن لا فأفيني. والفضاء الأفيني ليس فضاء متجهات لأنه لا يحوي الصفر.

٢ L = x₀ + U: نقطة إسناد وفضاء اتجاهSupport point plus direction space — a line or plane off the origin

ليكن U فضاءً جزئياً و x₀ متجهاً. المجموعة L = x₀ + U = {x₀ + u | u ∈ U} هي فضاء أفيني جزئي، وتسمّى x₀ نقطة الإسناد (support point) و U فضاء الاتجاه (direction space). صورتها الوسيطية: x = x₀ + λ₁b₁ + … + λₖbₖ.

توقّع قبل أن تجرّب

الدالة f(x) = Ax + b مع b ≠ 0. هل هي تطبيق خطي؟

اكشف الجواب

لا. f(0) = b ≠ 0، والتطبيق الخطي يرسل الصفر إلى الصفر دائماً. هي أفينية: تطبيق خطي تلته إزاحة. (Affine = linear + a shift; it loses the origin.)

نقطة الإسناد ليست وحيدة: أي نقطة على L تصلح إسناداً. أما فضاء الاتجاه U فوحيد — وهو الذي يحدد بُعد الفضاء الأفيني. (Support point: many choices. Direction space: one.)

٣ لماذا حلول Ax = b أفينية؟Particular solution plus the kernel — the shape of every solution set

مجموعة حلول Ax = b عند b ≠ 0 هي {x_p + v | v ∈ ker(A)}: حل خاص واحد زائد النواة كاملة. هذا هو تعريف الفضاء الأفيني حرفياً — نقطة إسناد x_p وفضاء اتجاه ker(A). ولهذا لا تكون مجموعة الحلول فضاءً جزئياً: الصفر ليس حلاً.

قارئ شكل مجموعة الحلول

أدخل n والرتبة وقيمة b — اللوحة تسمّي الشكل الهندسي

الشكل…
فكرة أساسية

المستوى الفائق (hyperplane) aᵀx = c فضاء أفيني بعده n − 1 — وهو الشكل الذي تفصل به خوارزميات التصنيف مثل SVM بين فئتين.

مثال محسوب

مجموعة حلول Ax = b مكتوبة على صورتها الحقيقية: نقطة إسناد زائد نواة.

A = [ 1  2  1 ]     b = [ 4 ]      one equation, three unknowns

  x1 + 2*x2 + x3 = 4

a particular solution   (set the free variables to zero)
  x2 = 0, x3 = 0   ->   x1 = 4
  x0 = (4, 0, 0)

the kernel   (the same equation with a zero right-hand side)
  x1 + 2*x2 + x3 = 0
  x2 = 1, x3 = 0   ->   x1 = -2    ->  u1 = (-2, 1, 0)
  x2 = 0, x3 = 1   ->   x1 = -1    ->  u2 = (-1, 0, 1)

the full solution set
  L = x0 + span{ u1, u2 }
    = (4, 0, 0) + span{ (-2, 1, 0), (-1, 0, 1) }

what shape is it?
  direction space has dimension 2   ->  a plane in R^3
  does it pass through the origin?
    (0,0,0):  0 + 0 + 0 = 0  !=  4    NO
  -> an affine plane, not a subspace

check one point of it
  x0 + 3*u1 = (4 - 6,  0 + 3,  0) = (-2, 3, 0)
  -2 + 2*3 + 0 = -2 + 6 = 4    OK

كل مجموعة حلول لمنظومة قابلة للحل لها هذا الشكل: حل خاص واحد، زائد النواة كلها. والفرق بين خطي وأفيني هو هذا الحل الخاص وحده.
