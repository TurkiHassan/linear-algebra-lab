التطبيقات الخطية: النواة والصورة

Linear Mappings — functions that respect addition and scaling, and the two subspaces they create

~40 دقيقة · المتطلب: الدرس 0012 (الرتبة)

١ التطبيق الخطي: دالة تحترم القواعدΦ(x + y) = Φ(x) + Φ(y) and Φ(λx) = λΦ(x)

التطبيق الخطي (linear mapping) هو دالة Φ : V → W تحقق شرطين: Φ(x + y) = Φ(x) + Φ(y) و Φ(λx) = λΦ(x). بعبارة أخرى: لا يهم أتجمع ثم تطبّق أم تطبّق ثم تجمع — النتيجة واحدة.

تشبيه: سعر الصرف

تحويل الريال إلى الدولار خطي: صرف ألفين مرة واحدة كصرف ألف مرتين، ومضاعفة المبلغ تضاعف الناتج. أما ضريبة ثابتة تُضاف بعد التحويل فتكسر الخطية فوراً — لأن الصفر لم يعد يذهب إلى الصفر. (A fixed fee breaks linearity.)

فكرة أساسية

القاعدة الذهبية: كل تطبيق خطي يحقق Φ(0) = 0 بالضرورة. فإن وجدت دالة لا ترسل الصفر إلى الصفر فقد انتهى الفحص — ليست خطية.

توقّع قبل أن تجرّب

تطبيق خطي من ℝ³ إلى ℝ². هل يمكن أن تكون نواته {0} فقط؟

اكشف الجواب

لا. الصورة تسكن ℝ² فبعدها ≤ 2، ونظرية الرتبة والنواة تعطي dim ker = 3 − dim Im ≥ 1. لا بد أن ينهار اتجاه واحد على الأقل. (Squeezing 3 dimensions into 2 must collapse something.)

فاحص الخطية

اختر دالة مرشحة — اللوحة تختبر الشرطين بأرقام حقيقية

شرطان… وحكم واحد

٢ النواة والصورة: ما يُهدَم وما يُبنىker(Φ) = what collapses to zero · Im(Φ) = what can be reached

النواة (kernel / null space) هي كل ما يرسله التطبيق إلى الصفر: ker(Φ) = {v | Φ(v) = 0}. والصورة (image / range) هي كل ما يمكن الوصول إليه فعلاً في الطرف الآخر. والاثنتان فضاءان جزئيان: النواة داخل V، والصورة داخل W.

انتبه

النواة ليست «مجموعة فارغة» أبداً: هي تحوي الصفر دائماً. فرقٌ حاسم بين ker = {0} (نواة صغرى، والتطبيق متباين) و«نواة فارغة» (شيء غير موجود أصلاً). (The kernel always contains 0.)

٣ نظرية الرتبة والنواةdim ker(Φ) + dim Im(Φ) = dim V — nothing is lost

ما يُهدَم وما يُبنى مجموعهما ثابت: dim ker(Φ) + dim Im(Φ) = dim V. وبلغة المصفوفات: nullity(A) + rk(A) = n — وهي المعادلة نفسها التي رأيتها في الدرس السابق. ومنها: Φ متباين (injective) ⟺ ker(Φ) = {0}، وشامل (surjective) ⟺ Im(Φ) = W، وتقابل (bijective) إذا اجتمعا.

فكرة أساسية

فضاءان منتهيا البعد متشاكلان (isomorphic) إذا وفقط إذا تساوى بعداهما. لهذا كل فضاء بعده n هو «نسخة» من ℝⁿ مهما بدا مختلفاً — كثيرات الحدود أو المصفوفات أو الإشارات.

مثال محسوب

تطبيق ينهار: نحسب نواته وصورته ثم نرى النظرية تُغلق الحساب.

A = [ 1  2 ]        Phi(x) = A x ,  from R^2 to R^2
    [ 2  4 ]

the kernel — what is sent to zero

  A x = 0
    x1 + 2*x2 = 0
  2*x1 + 4*x2 = 0        row 2 is exactly 2 * row 1: no new information

  so one equation only:  x1 = -2*x2
  take x2 = 1  ->  x1 = -2

  ker(Phi) = span{ (-2, 1) }          dim ker = 1

the image — what can be reached

  columns of A are (1, 2) and (2, 4) = 2 * (1, 2)
  only one independent direction

  Im(Phi) = span{ (1, 2) }            dim Im = rk(A) = 1

rank-nullity

  dim ker + dim Im  =  1 + 1  =  2  =  dim R^2      OK

check a kernel vector
  A * (-2, 1) = ( 1*(-2) + 2*1 ,  2*(-2) + 4*1 ) = (0, 0)   OK

الميزان لا يختل: ما يُهدَم زائد ما يُبنى يساوي بُعد الفضاء الأصلي دائماً. فإن رأيت الصورة تضيق، فاعلم أن النواة اتّسعت بالقدر نفسه.
