المولد والاستقلال الخطي

Span & Linear Independence — what a set reaches, and whether it wastes a vector

~45 دقيقة · المتطلب: الدرس 0007 (التركيب الخطي)

١ المولد: كل ما تصل إليه الخلطةSpan = the set of ALL linear combinations

المولد (span) لمجموعة متجهات هو كل النتائج الممكنة من كل الأوزان الممكنة. مولد (1,0) وحده هو المحور السيني كله. ومولد (1,0) و (0,1) هو ℝ² كله. السؤال: هل المجموعة «تولّد» هدفك؟ أي: هل الهدف تركيب منها؟

تشبيه: الخلاط مرة أخرى

عد إلى خلاط الدرس السابق: المكوّنات متجهات والكميات أوزان. المولد هو قائمة كل الأطعمة التي يمكن صنعها من هذه المكوّنات مهما غيّرت الكميات — لا مجرد الأطعمة التي جرّبتها. وبموزة وحليب تصنع عشرات المشروبات، لكن البيتزا تبقى خارج القائمة مهما فعلت: هي خارج المولد. والارتباط أن تضيف مكوّناً لا يوسّع القائمة أصلاً — عصير موز جاهز بجانب الموز والحليب لا يفتح لك طبقاً جديداً، لأنه نفسه خلطة منهما. Span is every dish you could make; a dependent vector is an ingredient that adds no new dish.

فكرة أساسية

القاعدة الذهبية: المولد سؤال «وصول»: w ∈ span{v₁,v₂} تعني «يوجد حل لمنظومة الأوزان». والاستقلال سؤال «هدر»: هل أحد المتجهات تركيب من البقية؟ (Span asks “reachable?” Independence asks “wasted?”)

٢ مختبر الاستقلال لمتجهينParallel ⟺ dependent in ℝ² — test it with the determinant

لمتجهين في ℝ² الاختبار فوري: متوازيان ⟺ مرتبطان خطياً (dependent)، وغير متوازيين ⟺ مستقلان (independent). والمحدد يحسم: det = 0 ⟺ مرتبطان. أدخل أي زوجين واحكم.

توقّع قبل أن تجرّب

ثلاثة متجهات مختلفة في ℝ². هل يمكن أن تكون مستقلة خطياً؟

اكشف الجواب

لا، مهما اخترتها. بُعد ℝ² هو 2، فأي ثلاثة متجهات فيه مرتبطة حتماً — أحدها تركيب من الآخرين. (More vectors than the dimension is always dependent.)

٣ المعادلة الصفرية هي المحكc₁v₁ + c₂v₂ = 0 with a nonzero weight ⟺ dependent

التعريف الدقيق: المجموعة مرتبطة خطياً إذا وُجدت أوزان ليست كلها صفراً تحقق c₁v₁ + c₂v₂ = 0، ومستقلة إذا كان الحل الوحيد هو الأوزان الصفرية. مثال: (1,1) و (2,2) مرتبطان لأن 2·(1,1) − 1·(2,2) = 0 بأوزان غير صفرية. حرّك الأوزان وجرب إصابة الصفر بغير الصفرية.

صيد الصفر بغير الصفرية

المتجهان (1,1) و (2,2) — حرّك الأوزان وحاول بلوغ (0,0) دون تصفيرهما

انتبه

أي مجموعة تحوي الصفري 0 مرتبطة تلقائياً (خذ وزنه 1 والبقية 0). وأي متجه منفرد غير صفري مستقل وحده. (Zero poisons independence; a lone nonzero vector is independent.)

مثال محسوب

زوجان في ℝ²: الأول مرتبط والثاني مستقل — والفرق رقم واحد.

pair 1     v1 = (2, 1)     v2 = (6, 3)

det [ 2  6 ]  =  2*3 - 6*1  =  6 - 6  =  0     -> dependent
    [ 1  3 ]

find a nonzero weight pair that kills them
  c1*(2,1) + c2*(6,3) = (0,0)
  take c2 = 1  ->  c1*(2,1) = -(6,3)  ->  c1 = -3
  check: -3*(2,1) + 1*(6,3) = (-6+6, -3+3) = (0, 0)   OK
  a nonzero solution exists  =>  dependent
  span{v1, v2} = a single line, not all of R^2


pair 2     w1 = (2, 1)     w2 = (1, 3)

det [ 2  1 ]  =  2*3 - 1*1  =  6 - 1  =  5  !=  0   -> independent
    [ 1  3 ]

  c1*(2,1) + c2*(1,3) = (0,0) forces c1 = c2 = 0
  span{w1, w2} = all of R^2

المحدد يجيب عن السؤالين معاً: صفرٌ يعني مرتبطين ومولّدهما خط، وغير الصفر يعني مستقلين ومولّدهما المستوى كله.
