الرتبة وحلّية المنظومة

Rank & Solvability — one number that counts the truly independent columns, and decides whether Ax = b has a solution

~35 دقيقة · المتطلب: الدرس 0009 (الأساس والأبعاد)

١ الرتبة: كم عموداً «مختلفاً حقاً»؟rk(A) = number of pivots = number of independent columns = number of independent rows

الرتبة (rank) ورمزها rk(A) هي عدد أعمدة المصفوفة المستقلة خطياً. والمفاجأة الجميلة: هذا العدد نفسه هو عدد الصفوف المستقلة، وهو نفسه عدد القادة (pivots) في الصورة الدرجية. ثلاث طرق للعدّ، ورقم واحد يخرج منها جميعاً.

تشبيه: فريق العمل

في فريق من خمسة موظفين، قد يكون ثلاثة منهم فقط يؤدون مهامّ مختلفة حقاً، والباقيان يكرّران عمل غيرهما. الرتبة هي عدد «المهام المختلفة» لا عدد الموظفين. (Five columns, but maybe only three distinct directions.)

فكرة أساسية

القاعدة الذهبية: احذف غاوسياً، ثم عُدّ القادة — هذا هو rk(A). ودائماً rk(A) ≤ min(m, n)، وعند المساواة نقول إن المصفوفة تامة الرتبة (full rank).

٢ محكمة الحلول: rk(A) ضد rk(A|b)Solvable iff rk(A) = rk(A|b); unique iff that rank also equals n

هنا تُحسم حالات الحل الثلاث التي عرفتها في الدرس 0003 بقاعدة واحدة دقيقة: المنظومة Ax = b لها حل إذا وفقط إذا كانت rk(A) = rk(A|b). فإن تساوتا وكانت الرتبة تساوي عدد المجاهيل n فالحل وحيد، وإن نقصت عنه فالحلول لانهائية.

انتبه

الرتبة تقول هل يوجد حل، ولا تقول ما هو الحل. هي كاشف وجود لا آلة حساب — بعدها تعود إلى الحذف الغاوسي لتستخرج القيم. (Rank answers «does a solution exist», not «what is it».)

٣ بعد فضاء الحل: n − rk(A)The solution space of Ax = 0 has dimension n − rk(A)

لكل مصفوفة A ∈ ℝ^(m×n)، فضاء حلول Ax = 0 بعده n − rk(A) بالضبط — وهذا هو عدد المتغيرات الحرة (free variables). كل قائد يقيّد متغيراً، وما بقي بلا قائد يبقى حراً. وللمصفوفة المربعة: rk(A) = n ⟺ لها نظير ⟺ محددها ≠ 0.
