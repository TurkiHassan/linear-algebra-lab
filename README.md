# مختبر الجبر الخطي

مقرر عربي تفاعلي في الجبر الخطي: ثلاثون درساً، وخارطة معرفية تربط مفاهيمه، وفيديو
بتعليق عربي للدروس الأحد عشر الأولى، ومراجعة متباعدة، وتمارين بايثون تعمل داخل المتصفح.

المحتوى مبنيّ من مصدرين: ملفات المقرر بخط اليد (الدروس 0001–0011)، وشرائح محاضرات
مقرر «الرياضيات الحاسوبية» — المحاضرة 02 · Linear Algebra (الدروس 0012–0015)،
والمحاضرة 03 · Analytic Geometry (الدروس 0016–0019)، والمحاضرة 04 · Matrix
Decompositions (الدروس 0020–0025)، والمحاضرة 05 · Vector Calculus (الدروس 0026–0030).

موقع ثابت بالكامل — بلا خادم وبلا بناء (no build step) وبلا اعتماديات على npm.
كل ملف HTML يُفتح مباشرة، ويعمل الموقع دون اتصال بعد أول زيارة عبر Service Worker.

## بنية المشروع

```
index.html              الفهرس: لوحة التقدّم، كتالوج الدروس، رحلة التعلّم، ثنائي اللغة (ar/en)
map.html                الخارطة المعرفية: 28 مفهوماً و37 علاقة، تخطيط طبقي محسوب من العلاقات
summary.html            الملخص الشامل: خارطة ذهنية لكل درس، أمثلة محلولة، لوحة التكافؤ الذهبي
review.html             المراجعة: جلسة مجدولة بـ SM-2 + تصفّح حر للبطاقات + ورقة غش للطباعة
search.html             بحث موحّد في المصطلحات ومحتوى الدروس
playground.html         مشغّل بايثون داخل المتصفح (Pyodide)
404.html                صفحة غير موجودة، تضبط جذر الموقع تلقائياً
lessons/00NN-*.html     الدروس الثلاثون — كل درس مستقل بنمطه الداخلي
practice/               تمارين بايثون + حلولها في practice/solutions
video/                  مولّد الفيديو (vidcore.py) ومخرجاته (mp4 + poster + srt + vtt)
```

### الأصول المشتركة (`assets/`)

| الملف | الدور |
|---|---|
| `site.js` | الوضع الداكن، تتبّع «أتممت الدرس»، عزل الاتجاه للنصوص اللاتينية، تسجيل الـ SW |
| `ui.js` | لوحة الأوامر (Ctrl/⌘+K)، اختصارات لوحة المفاتيح، فهرس الدرس، تصحيح الاختبار وحفظ الدرجة، «تابع من حيث توقفت»، سلسلة الأيام |
| `ui.css` | مكوّنات الواجهة المشتركة — تقرأ متغيّرات كل صفحة عبر `var(--x, fallback)` |
| `srs.js` | محرّك المراجعة المتباعدة: SM-2 بأربع درجات، طابور الجلسة، الإحصاءات، سجل النشاط |
| `graph-data.js` | عقد الخارطة وحوافها وروابط موارد كل مفهوم (و`NO_VIDEO` للدروس بلا فيديو) |
| `figure.js` | نواة لوحات الرسم: إحداثيات رياضية، ألوان من متغيّرات CSS، ومخزن على كثافة الشاشة |
| `search-data.js` | فهرس البحث (دروس، أقسام، مصطلحات) — مصدر بطاقات المراجعة أيضاً |
| `lesson.css` / `lesson-fonts.css` | إصلاحات RTL المشتركة وخطوط Thmanyah |

ترتيب التحميل في كل صفحة: `site.js` ثم `ui.js` (الثانية تعتمد على الأولى).

### التخزين المحلي

كل تقدّم المستخدم في `localStorage` فقط — بلا حساب وبلا خادم:

| المفتاح | المحتوى |
|---|---|
| `linalg:theme` | `"light"` أو `"dark"` |
| `linalg:done` | الدروس المكتملة `{ "0001": 1, ... }` |
| `linalg:seen` | الدروس التي فُتحت |
| `linalg:quiz` | درجة آخر اختبار لكل درس |
| `linalg:resume` | آخر درس وموضع القراءة فيه |
| `linalg:streak` | سلسلة أيام الدراسة |
| `linalg:srs` | جدولة كل بطاقة: `{ ef, reps, interval, due, lapses, last }` |
| `linalg:srs-log` | سجل المراجعة اليومي (180 يوماً) |

## الخارطة المعرفية

`assets/graph-data.js` يعرّف العقد والحواف. أنواع الحواف:

- `need` — متطلّب سابق (خط متصل)
- `use` — يستخدمه في الحل (خط متقطّع)
- `equiv` — تكافؤ منطقي (نقاط)

تخطيط الصفحة **محسوب وقت التشغيل** لا مكتوب يدوياً: رتبة كل عقدة = أطول مسار
يصل إليها، فيضمن ذلك أن كل سهم يتجه للأسفل وأن أي مفهوم يقع تحت كل متطلباته.
لإضافة مفهوم: أضف `n(...)` إلى `NODES` و`e(...)` إلى `EDGES` — ولا حاجة لضبط أي
إحداثيات. الرسم البياني يجب أن يبقى **خالياً من الدورات**.

## المنهجية التعليمية

البناء يتبع ما تدعمه أبحاث التعلّم:

- **الاسترجاع النشط** — اختبار يختم كل درس، ودرجته تُحفظ وتظهر في لوحة التقدّم
- **التباعد** — بطاقات SM-2 تعيد المصطلح قبل نسيانه بقليل
- **الترميز المزدوج** — نص + لوحة متحركة + فيديو معلّق للفكرة نفسها
- **التداخل** — بنك التدريبات (الدرس 0011) يخلط المحاور الثلاثة الأولى
- **خرائط المفاهيم** — `map.html` تُظهر متطلبات كل فكرة وما يُبنى فوقها
- **التشبيهات الملموسة** — تشبيه واحد من الحياة لكل مفهوم

## أدوات البناء

```bash
python3 scripts/gen_data.py     # يعيد توليد فهرس البحث وملفات التمارين
```

- **`scripts/build_lesson.py`** — قالب صفحة الدرس: الهيكل الذي تشترك فيه كل
  الدروس (الوسوم، والمسار، والأدوات، والمراجع، وسكربت الاختبار). يُستورد من
  ملف مواصفة يصف الدروس ثم يكتبها:

  ```python
  from build_lesson import write_all
  write_all([L26, L27])
  ```

  والمواصفة قاموس فيه `id` و`slug` و`ar` و`body` و`script` وأخواتها، و`canvas=True`
  إن كان في الدرس لوحة رسم — فيُحمَّل `assets/figure.js` قبل سكربت الدرس وتُربط أسماؤه.

- **`scripts/gen_data.py`** — `assets/search-data.js` و`assets/exercises.js`
  مولَّدان بالكامل من ملفات الدروس والتمارين، فلا يُحرَّران يدوياً. يُشغَّل بعد
  كل إضافة أو تعديل لدرس.

## بوابة الجودة

```bash
node scripts/audit-lessons.mjs                 # كل الدروس
node scripts/audit-lessons.mjs 0017            # درس بعينه
node scripts/audit-lessons.mjs --errors-only   # الأخطاء القاطعة فقط
node scripts/audit-lessons.mjs --only bidi     # فئة واحدة
```

فحص آلي بلا متصفح ولا نموذج لغوي. مخرجاته نوعان:

- **ERROR** — عيب موضوعي يجب إصلاحه: رقم غير معزول في نص عربي (يُعرض مقلوباً)،
  قاموس أو قسم «ماذا كسبت؟» ناقص، سؤال بلا إجابة صحيحة، تمرين مفقود، لوحة بلا
  `figure.js`، إيموجي في المتن، أو درس غير مربوط بإحدى صفحات الموقع.
- **hint** — مؤشر عمق تحكم أنت فيه: لا مثال محسوب، لا سؤال توقّع، دالة في
  التمرين لا يسمّيها الدرس، لوحات الدرس ببصمة واحدة (أقل من ثلاث قواعد تفاعل).

الأمر يخرج بـ `1` عند أي `ERROR`، فيصلح لبوابة قبل الدفع.

**الحالة الآن: 30 درساً · صفر `ERROR` · صفر `hint`.** فكل درس فيه بطاقة
«توقّع قبل أن تجرّب» ومثالاً محسوباً وقائمة دوال التمرين ولوحة رسم، وكل درس
بثلاث لوحات أو أكثر فيه ثلاث قواعد تفاعل على الأقل. الحفاظ على الصفر شرط
لأي درس جديد.

## لوحات الرسم

`assets/figure.js` هو النواة، ويُحمَّل **قبل** سكربت الدرس:

```html
<script src="../assets/figure.js"></script>
```

```js
var FIG = LinalgFig.FIG, onTheme = LinalgFig.onTheme, plane = LinalgFig.plane;
var fig = FIG("cvId");
function draw(){
  var c = fig.col();                      // ألوان السمة الحالية
  fig.fit([a, b]).clear();                // المقياس والأصل من المحتوى
  fig.grid().arrow([0,0], a, c.accent);
}
onTheme(draw); draw();                    // يُعاد الرسم عند تبديل السمة أو المقاس
```

`plane(a, b)` يرسم متجهي `ℝⁿ` داخل المستوى المشترك بينهما، فالزاوية والمسافة
المعروضتان حقيقيتان لا إسقاطاً مشوّهاً.

`fig.label(p, نص, لون, بُعد)` يضع الوسم مزاحاً بعيداً عن الأصل في اتجاه `p`،
فلا يركب رأسَ السهم مهما كان اتجاهه.

كل دوال الرسم تعيد `fig` فتتسلسل: `fig.fit(pts).clear().grid().arrow(...)`.

**عقد اللوحة في `assets/lesson.css` لا في كل درس:**

```css
canvas{width:100%;max-width:640px;height:auto;display:block;margin:14px auto; ... }
```

`max-width` ليس زينة. اللوحة بلا سقف عرض تتغذّى على تحجيمها: `LinalgHiDPI`
يكبّر المخزن بحسب المقاس المعروض، والمخزن يكبّر الصندوق لأن `height:auto`
يقرأ نسبة المخزن — فتنمو اللوحة في كل رسم حتى تبتلع الصفحة.

## التطوير

```bash
# معاينة محلية (أي خادم ثابت يكفي)
python3 -m http.server 8000
```

ملاحظات عند التعديل:

- **الاتجاه داخل SVG**: النصوص داخل `<svg>` ليست HTML — لا تُحقن فيها عناصر HTML
  (مثل `<bdi>`) وإلا اختفت تماماً. `site.js` يتخطّى أي فضاء أسماء غير HTML لهذا السبب.
- **ترجمات الفيديو**: المتصفحات تقبل WebVTT فقط في `<track>` ولا تقبل SRT.
  `vidcore.py` يكتب الصيغتين؛ الصفحات تشير إلى `.vtt`.
- **الـ Service Worker**: أي أصل جديد يُضاف إلى `CORE` في `sw.js` **مع رفع رقم `CACHE`**،
  وإلا بقي المستخدمون على النسخة المخزّنة.
- **ثنائية اللغة في `index.html`**: كل مفتاح في `I18N.ar` يلزمه نظير في `I18N.en`.
- **الأرقام في النص العربي**: كل إحداثي أو نطاق رقمي داخل `<span class="coord">`،
  وإلا عُرض مقلوباً. `site.js` يعزل النصوص اللاتينية تلقائياً، لكنه **لا يلتقط**
  ما لا حرف فيه مثل `(1,1)` أو `0001–0010`. البوابة تكشفها.
- **عند إضافة درس**: الملف في `lessons/`، وتمرينه في `practice/` وحلّه في
  `practice/solutions/`، ثم قيده في `assets/graph-data.js` (`SLUG` و`LESSON_TITLES`
  و`NODES` و`EDGES`)، وفي `index.html` (البطاقة والصف و`IDS` ومفاتيح `I18N`)،
  وفي `review.html` و`summary.html` و`playground.html` و`sitemap.xml` و`sw.js`.
  أما `assets/search-data.js` و`assets/exercises.js` فيُعاد توليدهما بـ
  `python3 scripts/gen_data.py`.
